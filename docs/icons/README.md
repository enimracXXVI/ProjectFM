# ProjectFM section icons

The icons of the app's sections (sidebar and phone bottom bar), for reuse such as PWA shortcut
icons.

- `svg/`: the icons themselves (24 × 24, 2px stroke, `currentColor`, so they take any colour).
- `png-96/` and `png-192/`: ready-made shortcut icons, green (#22c55e) on the app's
  background (#0b1120), with a margin so they survive a round mask.

All but `tactics` are [Lucide](https://lucide.dev) icons (ISC licence, free to reuse with the
licence notice); `tactics` is ProjectFM's own pitch icon drawn in the same style.
